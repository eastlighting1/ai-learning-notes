# AI Learning Notes

OpenAI, Anthropic, Google, Microsoft에서 제공하는 AI 관련 강의를 수강하며 공부한 내용을 정리하는 저장소입니다.

생성형 AI와 대규모 언어 모델(LLM)의 기본 개념부터 프롬프트 엔지니어링, AI 에이전트, 실제 서비스에 활용하는 방법까지 학습하고 있습니다.

강의 내용을 단순히 요약하기보다는 이해한 내용을 제 방식대로 정리하고, 궁금한 부분은 추가로 찾아보며 공부한 내용을 기록하려고 합니다.

## Topics

- **Generative AI** — 생성형 AI의 기본 개념과 작동 원리
- **Large Language Models** — LLM의 구조, 특징 및 한계
- **Prompt Engineering** — 효과적인 프롬프트 작성 및 개선 방법
- **AI Agents & Workflows** — AI 에이전트와 워크플로 자동화
- **AI Development** — API, MCP 및 AI 기반 애플리케이션 개발
- **Responsible AI** — AI의 안전성, 윤리적 문제 및 책임 있는 활용
